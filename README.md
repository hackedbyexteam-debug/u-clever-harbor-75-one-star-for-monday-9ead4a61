A one-star review of Monday, written as if Monday were a restaurant — one line, 25 words or fewer.

## Entry

> One star. Waited forty minutes for a table, got served a cold plate of meetings, and the waiter charged me the whole weekend.

## Run

```sh
node main.ts
```

Writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
